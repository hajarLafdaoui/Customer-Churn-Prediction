# Customer Churn Prediction

Predicts if a customer will leave your business using machine learning.

## How to Run

1. Install packages: `pip install -r requirements.txt`
2. Generate data: `python src/create_data.py`
3. Train model: `python src/train_model.py`
4. Launch app: `streamlit run app.py`

## Features

- Predict churn probability
- Low/Medium/High risk levels
- Retention recommendations
- Simple web interface

## Technologies

Python, Scikit-learn, XGBoost, Streamlit, Pandas

## Model Accuracy

85% F1-Score
